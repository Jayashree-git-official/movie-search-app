Add to Cart Application
This project is a single-page React application that simulates an e-commerce product catalog. It fetches product data from the Fake Store API and allows users to add and remove items from a shopping cart using a persistent state and a modal interface.

Tech Stack
ReactJS: For building the user interface and managing component logic.

JavaScript (ES6+): For functionality and state management.

Tailwind CSS: For fast and responsive utility-first styling.

Fake Store API: Used as the data source for product information.

Features
Data Fetching: Products are fetched asynchronously from a public API.

Responsive Product Grid: Products are displayed in a responsive grid layout.

Cart State Management: Manages the list of items in the cart.

Alerts: Displays an alert if a user tries to add an item already in the cart.

Navbar Counter: The number of items in the cart is displayed in the navigation bar.

Cart Modal: A dedicated modal displays all cart items, their total price, and allows items to be removed.

Props Usage: Necessary data (cart, product, and handler functions) is passed down to child components using props.
